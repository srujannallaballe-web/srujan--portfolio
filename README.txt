SRUJAN PORTFOLIO — QUICK START

1. Extract this ZIP.
2. Open index.html in your browser.
3. To edit the website:
   - index.html = words/content
   - style.css = colours, layout and design
   - script.js = interactions
4. Replace hello@example.com in index.html with your real email.
5. Replace project descriptions/links with your real work.
6. When ready, upload the folder to a hosting service such as GitHub Pages, Netlify or Vercel.
7. You can then connect a custom domain such as srujan.dev or srujan.in.

No database or installation is required for this version.
